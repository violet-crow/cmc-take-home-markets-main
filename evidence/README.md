# Evidence pack

The domain team's source material, in the vocabulary it was written in. The content is accurate. Its grouping and hierarchy reflect the team's research structure rather than a data model.

| File | What it is | Where it came from |
|---|---|---|
| `E1_scope_list.csv` | The domain team's list of the rule sets it tracks, one row each, with its own codes | The domain team's post-approval change matrix |
| `E2_country_summary.csv` | A per-country summary: agency, framework, categories, notable differences, the team's confidence | The domain team's country summary, trimmed to the countries in scope |
| `E3_category_codes.csv` | Every reporting category in the matrix for the rule sets in scope, keyed as the matrix keys them | The same matrix |
| `E4_asean.md` | Primary-source notes on the ASEAN Variation Guideline and each member | The regulatory team's primary-source review |
| `E5_eu_structure.md` | How licensing and variations work across the EU, EEA, UK and Switzerland | Public sources |

The countries in scope are: United States, the EU with Germany, France and Norway, United Kingdom, Switzerland, Saudi Arabia, South Africa, China, Brazil, Mexico, Argentina, and the eleven ASEAN members.
